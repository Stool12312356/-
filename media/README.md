# media/ — только локально

Эта папка **исключена из Git** (см. `.gitignore`). Сюда складываются крупные исходники:
видео, аудио, RAW, PSD/AI, рендеры, архивы.

Почему: у воркспейса Arena есть лимит снапшота — **128 МБ и 10 000 файлов**.
Всё, что лежит в репозитории, считается в этот лимит и при превышении перестаёт сохраняться
(часть файлов теряется между шагами). Поэтому медиа живёт только у вас на компьютере.

## Куда что кладём

| Тип файла | Где живёт | В Git? |
|---|---|---|
| Код, скрипты, конфиги | `src/`, `scripts/` | да |
| Мелкие иконки/логотипы (< 200 КБ) | `assets/` | да |
| Видео, аудио, RAW, PSD, рендеры | `media/` | нет |
| Временная работа (можно потерять) | `/tmp/media-work` | нет, и в снапшот не идёт |

## Как передать мне крупный файл

Кладите его **во вложение в чат**, а не в проект. Если файл нужен для сборки —
я работаю с ним из `/tmp/media-work`, и он не расходует бюджет снапшота.
