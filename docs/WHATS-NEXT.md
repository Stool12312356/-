| Размер файла | один файл больше 100 МБ не скачивается | архив воркспейса (211 МБ) недоступен |

| Нет браузера | Chromium не устанавливается (нет сети для загрузки) | я не вижу картинку игры, только логику |

Что это **не** значит: что я не могу работать. Могу — и уже починил три поломки,
которые бы вас остановили. Просто финальный шаг (сжатие 386 МБ) физически
должен произойти там, где эти 386 МБ лежат.

## Вариант А — рекомендуемый (5 минут)

У вас уже есть папка с исходниками на компьютере.

1. Скачайте с Диска папку **`assets/models`** (49 GLB, 343 МБ) к себе — нужно только для пересборки, сжатые модели уже в репозитории.
2. В корне проекта (там, где `package.json`) положите их в `assets/models/`.
3. Выполните:
   ```bash
   npm install
   npm run assets
   ```
   Скрипт сам: разрежет паки на отдельные модели, сожмёт текстуры в WebP,
   применит Draco, посчитает коллидеры и пересоберёт `manifest.json`.
   Ожидаемый результат: **386 МБ → примерно 20–25 МБ**.
4. Залейте на Диск в папку «Игра» **две вещи**:
   - `public/assets/game` (сжатые модели)
   - `public/assets/colliders` (коллайдеры)
   - и `public/assets/manifest.json`

Всё. Дальше я подхвачу и займусь M2.

## Вариант Б — если запускать локально не хочется

Загрузите сырые модели на Диск **по частям**, архивами меньше 100 МБ каждый,
например `models_part1.zip` … `models_part5.zip`. Я скачаю по одному,
распакую, сожму и выброшу сырое — бюджет выдержит, потому что храню по очереди.

Минус: дольше и возни больше. Плюс: ничего не устанавливать.
