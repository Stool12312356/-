# Журнал багов и решений (M1 → M2)

Файл для следующего ИИ-разработчика. Здесь: что уже сделано, какие баги находили,
как их проверять и что осталось незакрытым. **Прежде чем что-то менять — прочитайте
раздел 5 «Грабли, на которые уже наступали»**: там ошибки, которые съедают часы.

## 1. Состояние на конец M2 (эта ветка)

- **Ассеты:** 76 настоящих моделей из 81 предмета. Заглушки: `aks74u`, `barrel`, `crate`.
  Процедурные (кодом, не из файла): `khrushchevka`, `brezhnevka`.
- **Баллистика:** физические снаряды в воркере, гравитация + сопротивление воздуха,
  пробитие/рикошет по материалам, трассеры, пробоины, искры.
- **Оружие:** АК-74, АК-74М, АКМ, СВД, ПКМ, РПК, ПМ, M4A1, AWM/L96, PGM, РПГ-7.
  Переключение 1–4 / Q, перезарядка R, прицеливание ПКМ (FOV 75 → 45).
- **Разрушения:** панельки с интерьером (2 типа), панели с HP, обломки как физические тела,
  обрушение секции при потере 65 % несущих.
- **Проверки без браузера:** `npm test` — баллистика, дома, разрушения, сползание (раздел 4).

## 3. Известные ограничения (не баги, но помнить)

1. **Браузера в песочнице нет.** `npx playwright install chromium` падает (нет доступа к
   хранилищу браузеров). Поэтому визуально игру проверить нельзя: только `tsc`, `vite build`,
   Node-тесты и curl. Скриншоты пользователя — единственный источник правды о картинке.
2. **Интерьер дома не освещён.** Внутри темно: люстры — это геометрия, а не источники света
   (PointLight на 300 квартир убьёт FPS). Нужен световой объём: emissive-материалы люстр,
   фейковый ambient внутри, либо один свет на подъезд с ограничением дальности.
3. **Ботов ещё нет как ИИ.** В `bots.ts` — мишени: стоят, получают урон, падают импульсом.
   Navmesh, отряды, 32×32 — этап M5.
4. **Рэгдолл упрощённый:** один бокс-коллайдер на тело, без сочленений. Нормальный рэгдолл —
   после M5, когда появятся скелеты с анимациями.
5. **Пули не damaging технику.** У техники `surface: 'concrete'` по умолчанию, броня
   помечена `armor` только в баллистике. Нужен отдельный слой «попадание в технику» → урон узлам.
6. **`aks74u` остаётся заглушкой:** в паке АК-74 отдельной модели АКС-74У нет. Подменять
   другой моделью запрещено (п. ТЗ).
7. **Кратеров в террейне нет:** `heightfield` пересобирается тяжело, отложено до M3.
8. **Лимит обломков** — 220 физических блоков на дом (`MAX_DEBRIS`), остальные удаляются.
9. **Воксель — не «песок»:** шаг 1.4 × 0.7 м. Меньше делать нельзя без потери FPS
   (26 000 блоков на дом физика не тянет). Пробоину размером с дверь даёт залп РПГ.
10. **Кратеров в земле пока нет** — высотное поле (heightfield) пересобирается тяжело.

## 3.1. Устройство воксельного дома (читать перед правками)

- Генератор: `src/game/buildings.ts` → `buildBuilding()` выдаёт `walls: VoxelWall[]`
  (блок стены 1.4 × 0.7 × 0.32, перекрытие 2.5 × 0.3 × 2.5), окна-проёмы как
  отсутствующие блоки, мебель отдельным списком.
- `VoxelBuilding` (`src/game/voxel.ts`) собирает стены в СЕТКИ (`grids`), хранит `cells`,
  строит физику и рендер.
- **Целый дом = 1 форма физики** (габаритная коробка). Это важно: 5000 коробок в статике
  Rapier стоят слишком дорого, а целое здание всё равно непроходимо.
- После первого разрушения `rebuildPhysics()` заново собирает формы по живым блокам,
  сливая подряд идущие блоки в один прямоугольник (≤ 2500 форм).
- `enforceSupport()` — перед пересборкой: BFS от земли и от плит, всё недостигнутое падает.
  Опоры: земля, плита, под краем которой есть живая стена, и связность через соседей.
- Колонны: `column: true` у несущего пояса по фасаду и по торцам. `structure(section)`
  и HUD показывают, сколько колонн осталось. 66 % уничтожено → `collapseSection()`.

## 4. Как проверять (без браузера)

```cmd
npm run test:ballistics    :: попадание в панель, пробитие по материалам, настильность
npm run test:buildings     :: сколько панелей/несущих/мебели в домах
npm run test:destruction   :: пуля vs блок, РПГ vs стена, обрушение секции, висящие блоки
npm run test:slide         :: сползание: 30/42° стоим, 45-60° съезжаем
npx tsc --noEmit           :: типы
npx vite build             :: сборка
```

Ожидаемые цифры (эталон на этой ветке):

```
хрущёвка:  5505 блоков (5055 стен + 450 перекрытий), 140 колонн (60/20/60), ~230 мебели
брежневка: 6842 блока (6342 + 500), 216 колонн (108/108), ~283 мебели
разрушения: пуля — 1 блок; РПГ — ~16 блоков; секция падает после сноса 66% колонн
опора: после всех разрушений висят 0 блоков (тест проверяет это явно)
настильность: АК-74 278 м, СВД 261 м, ПМ 99 м, РПГ 38 м (просадка 0,5 м)
```

## 5. Грабли, на которые уже наступали (не повторять)

- **Rapier: `castRay` возвращает `null`, пока не вызван `world.step()`.** Query pipeline
  строится на шаге мира. В тестах обязательно `world.step()` перед первым лучом.
- **Rapier `castRay` — это swept-отрезок, а не точка.** Поэтому 900 м/с не «туннелирует»
  статику. Подшаги в `stepProjectile` всё равно нужны: за кадр пуля проходит 15 м и может
  перескочить движущуюся цель или пробить две панели подряд.
- **`lib.make(id)` для процедурного предмета падает** — у него нет файла. Проверяйте
  `item.procedural` до вызова.
- **PBR-металл без `scene.environment` — чёрный.** Если модель «пропала», проверьте
  `metalness`/`roughness` в GLB прежде чем менять геометрию.
- **`assets/models` и `assets/_split` в `.gitignore`** — сырые ассеты (343 МБ) в репозиторий
  не кладутся, только сжатые `public/assets/game` (25 МБ).
- **Windows/PowerShell:** `npm.ps1` может быть заблокирован → `cmd`, либо
  `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`.
- **bash-синтаксис в `package.json`** (`TEXMAX=128 node ...`) на Windows не работает — только флаги.
- **Кириллица в именах файлов** ломается в zip (`#U0422#U0417`) — документация латиницей.
- **Устаревшая копия проекта.** Если поведение не меняется — проверьте
  `node -e "console.log(require('./package.json').scripts.assets)"`.
- **Не подставлять одну модель под другой предмет** (прямое требование ТЗ): лучше заглушка.
