# Красный Шторм — M2 (оружие, баллистика, разрушаемые панельки)

Одиночный шутер в браузере, 100% офлайн (сервера нет). Стек: Three.js, Rapier3D (WASM, Web Worker, 60 Гц), TypeScript, Vite.

## Запуск
```
npm install
npm run dev          # http://localhost:5173  (manifest пересобирается автоматически)
npm run build && npm run preview   # статическая сборка в dist/
```
Параметры URL для слабых машин: `?lowtex` (текстуры 128px), `?noshadow`, `?lowres`.

## Ассеты (папка Google Drive)
1. `npm run download` — gdown в `assets/models/`
2. `npm run assets` — конвертация (`tools/convert.mjs`: Specular-Glossiness→PBR, Draco, текстуры WebP ≤512/1024) + `tools/build-manifest.mjs` (классификация, нормализация масштаба/ориентации, коллайдеры convex hull → `public/assets/colliders/`, реестр `public/assets/manifest.json`)
3. **Правило «одна модель — один предмет»**: `config/catalog.json` описывает каждый предмет и regexp имени файла. Если один файл подходит под два id — файл пропускается с предупреждением, остальные собираются. Если файла нет — рисуется отдельная процедурная заглушка (`placeholder:true`), а не чужая модель. Положите нужный файл (например `ak74.glb`) в `assets/models`, выполните `npm run assets` — заглушка заменится без правки кода.

Реестр в игре: клавиша **Tab** (какие модели настоящие, какие — заглушки).

## Управление (M2)

| Клавиша | Действие |
|---|---|
| ЛКМ / ПКМ | стрельба / прицеливание (FOV 75 → 45) |
| R | перезарядка |
| 1–4, Q | оружие: АК-74, СВД, РПГ-7, ПМ (или следующее) |
| WASD, Shift, C, Z, Space | движение, спринт, присед, лёжа, прыжок |
| G | взрыв (проверка разрушений), F — бросить ящик, B — респавн |
| Tab | реестр ассетов |

## Баллистика и разрушения (M2)

- **Пуля — физический снаряд**, а не хитскан: гравитация, сопротивление воздуха
  (у каждой пули свой баллистический коэффициент), падение скорости, время полёта.
  Расчёт идёт в физическом воркере подшагами 1/600 с.
- **Пробитие по материалам:** панель/бетон/кирпич/дерево/стекло/металл/броня. Скользящее
  попадание требует большего пробития, от металла возможен рикошет. В HUD показывается
  «ПАНЕЛЬ · ПРОБИТО» или «БЕТОН · ЗАДЕРЖАЛА».
- **Разрушения:** фасад панельки нарезан на панели с HP. Пуля (6–17 попаданий) или РПГ
  выбивает панель → в стене дыра, на её месте физические обломки. Несущие панели при
  потере 65 % секции роняют весь подъезд.
- **Панельки строятся кодом** (`src/game/buildings.ts`), с квартирами и мебелью —
  чтобы была разрушаемость и интерьер, чего не даёт готовый GLB.

## Проверки без браузера

